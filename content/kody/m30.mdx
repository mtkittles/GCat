**M30** i **M02** kończą program. Różnią się tym, co sterowanie robi potem — a to ustalają parametry i producent maszyny.

## Co dokładnie robi M30 \{#co-dokładnie-robi-m30}

* **Przewinięcie na początek programu** — ustala parametr: na Fanucu 0i-F 3404#4 dla M30 i 3404#5 dla M02. Zwykle M30 przewija, a M02 nie.
* **Wrzeciono, chłodziwo, reset funkcji modalnych** — na większości maszyn M30 je zatrzymuje i kasuje, ale zakres ustala producent maszyny.
* **Licznik detali** — jeśli maszyna go prowadzi, kod, który go zwiększa, zależy od sterowania.

Program nie powinien polegać na tym, co zrobi M30: w programach kursu M09 i M05 stoją przed nim (lekcja F1.5).

## Zakończenie programu w praktyce \{#zakończenie-programu-w-praktyce}

Samo M30 nie odsuwa narzędzia. Pełne, bezpieczne zakończenie wygląda tak:

<Code caption="Kolejność ma znaczenie: najpierw wyjdź z materiału, potem wyłączaj.">
  ```
  G00 Z50.    (odjazd na Z bezpieczne)
  M09         (chłodziwo wyłączone)
  M05         (wrzeciono zatrzymane)
  G91 G28 Z0. (Z do punktu referencyjnego)
  G90         (powrót do trybu absolutnego)
  M30         (koniec programu)
  ```
</Code>

| Kod     | Działanie                                                                                                   |
| ------- | ----------------------------------------------------------------------------------------------------------- |
| **M00** | Zatrzymanie bezwarunkowe w środku programu — do pomiaru albo obrócenia detalu. Wznowienie przyciskiem Start |
| **M01** | Zatrzymanie warunkowe — działa tylko, gdy operator włączył Optional Stop na pulpicie                        |
| **M02** | Koniec programu; przewinięcie wg parametru (Fanuc 3404#5) — zwykle bez                                      |
| **M30** | Koniec programu; przewinięcie wg parametru (Fanuc 3404#4). Standard w nowych programach                     |
| **M99** | Koniec podprogramu; w programie głównym powoduje pętlę nieskończoną                                         |

<Note kind="tip">
  **M01** to bardzo przydatne narzędzie przy uruchamianiu nowego programu. Wstaw je po każdym narzędziu — przy włączonym Optional Stop maszyna zatrzyma się po każdym zabiegu, żebyś mógł zmierzyć detal. Po zatwierdzeniu programu wyłączasz Optional Stop i te same bloki są ignorowane.
</Note>
